## Retningslinjer for billeder og grafik

1. **Tilgængelighed og alternativ tekst (`alt`-attribut):**
   - Alle indholdsbærende billeder på hjemmesiden skal have en meningsfuld og beskrivende `alt`-tekst for skærmlæsere og svagtseende brugere.
   - For `Storskraldrum.png` benyttes fx: `alt="Oversigtskort over zoner og containere i storskraldsrummet under Skyttegårdvej 5"`.

2. **Weboptimering og formater:**
   - Billeder skal komprimeres med værktøjer som TinyPNG, ImageOptim eller WebP-konvertere for at minimere filstørrelsen og sikre lynhurtig indlæsning.
   - Diagrammer, skitser og illustrationer med skarpe linjer bør gemmes som PNG eller SVG, mens fotografiske optagelser gemmes som optimeret JPEG eller WebP.

3. **Oprydning af skabelonbilleder:**
   - Tidligere skabelonbilleder fra HTML5 UP-designet (`pic01.jpg` til `pic11.jpg`) samt midlertidige `.bak`-kopier er blevet fjernet for at holde repositoryet ryddeligt, sikkert og produktionsklart. Kun billeder med reel funktion for ejerforeningen må opbevares her.

4. **GDPR, privatliv og rettigheder:**
   - Offentliggjorte fotografier må ikke vise genkendelige personer, beboere eller børns ansigter uden forudgående skriftligt samtykke.
   - Kontroller altid, at bilers registreringsnumre (nummerplader) sløres på udendørsbilleder før upload.
