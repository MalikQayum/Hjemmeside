# Billeder

Indeholder billedfiler, der bruges af hjemmesidens sider og design.

## Sådan vedligeholdes billeder

Før et billede udskiftes eller omdøbes, søg efter filnavnet i HTML og CSS, og opdatér alle referencer samtidig. Bevar eksisterende navne, når billedet blot får en ny version. Brug beskrivende alternativ tekst på indholdsbilleder, og kontrollér billedets visning i de relevante skærmstørrelser.

Tilføj kun billeder, der må offentliggøres. Kontrollér brugsrettigheder, filstørrelse og at billedet ikke indeholder utilsigtede personoplysninger. Sikkerhedskopier som `.bak` er ikke en del af hjemmesidens visning.
