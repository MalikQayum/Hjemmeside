# Husorden og vedtægter

Denne mappe indeholder hjemmesidens side til visning af foreningens husorden og vedtægter.

De officielle dokumenter ligger i repository'ets rod som `Husorden.pdf` og `Vedtægter.pdf`. Siden `index.html` viser dokumenterne i browseren. Ved ændringer i regler skal de officielle dokumenter være den autoritative kilde; opdatér ikke kun sidetekst eller chatbotdata.
