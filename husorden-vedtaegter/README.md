# Husorden og vedtægter

Denne mappe indeholder hjemmesidens side til visning af foreningens husorden og vedtægter.

De aktuelle dokumenter ligger i repository-roden som `Husorden.pdf` og `Vedtægter.pdf`. Siden `index.html` viser dokumenterne i browseren via PDF-viseren og linker til originalfilerne.

Hvis et dokument opdateres, skal den godkendte fil placeres i roden med det forventede filnavn, så sidevisning og download fortsat virker. Kontrollér dokumentet efter publicering. Ved ændringer i regler er de officielt vedtagne dokumenter den autoritative kilde; opdatér ikke kun sidetekst eller chatbotdata.
