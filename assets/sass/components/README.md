# Sass - komponenter

Genanvendelige visuelle komponenter i hjemmesidens design, eksempelvis knapper, formularer, tabeller, lister, billeder, kontaktblokke og indholdssektioner.

Redigér den komponentfil, der svarer til elementet. Søg efter sider, der bruger komponenten, kompilér derefter `main.scss` til `../css/main.css`, og kontrollér alle berørte sider. Komponentændringer kan påvirke flere sider, end den første visuelle prøve viser.
