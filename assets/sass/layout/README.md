# Sass - layout

Overordnede layoutdele for hjemmesiden: wrapper, header, sidebar, menu, main-indhold, banner og footer.

Redigér den relevante layoutfil, kompilér `main.scss` til `../css/main.css`, og kontrollér alle sider, der bruger layoutet. Ændringer kan påvirke hele hjemmesidens struktur og responsive visning; test både desktop og mobil efter ændringer.
