# Sass - base

Grundlæggende styling for typografi, sideopsætning og CSS-reset. Ændringer her kan påvirke mange eller alle sider.

- `_typography.scss`: typografi og tekstopsætning.
- `_page.scss`: generelle sideregler.
- `_reset.scss`: normalisering/reset af browserstandarder.

Redigér kun disse filer for grundlæggende stilregler, der skal gælde på tværs af hjemmesiden. Efter ændringer skal `main.scss` kompileres til `../css/main.css`; se Sass-mappens README for fremgangsmåde. Kontrollér både typografi, links og sidens grundlayout på flere skærmstørrelser.
