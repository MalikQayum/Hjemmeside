# Assets – hjemmesidens ressourcer

Denne mappe indeholder de statiske ressourcer, som hjemmesidens sider bruger: stylesheets, JavaScript, geografiske data, Sass-kilder, video og webfonts.

## Undermapper
- `css/`: færdige stylesheets, som indlæses af hjemmesiden.
- `js/`: browserfunktionalitet og sidekomponenter.
- `data/`: GeoJSON, KML og øvrige datafiler til kortet.
- `sass/`: Sass-kildekode opdelt i base, layout, komponenter og biblioteker.
- `video/`: videomateriale til hjemmesiden.
- `webfonts/`: skrifttypefiler og ikonfonte.

Ændr kun de ressourcer, der er nødvendige for opgaven. Bevar eksisterende filstier, da HTML-siderne refererer direkte til dem.
