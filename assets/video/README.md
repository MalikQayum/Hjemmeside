# Video

Indeholder videofiler, der bruges som visuelt indhold på hjemmesiden.

`ejerforeningen-3d.mp4` er den eksisterende 3D-video af ejendommene. Den er et færdigt medieasset; udskift eller redigér den kun efter en konkret beslutning. HTML/CSS styrer, hvordan videoen vises på siden.

## Sådan vedligeholdes videoer

Før en fil udskiftes eller omdøbes, søg efter dens navn i sidernes HTML og kontrollér alle referencer. Bevar det nuværende format, medmindre afspilning på de understøttede browsere er kontrolleret. Efter udskiftning skal videoen afprøves på selve siden, herunder dens beskæring og visning på mobil.

Videoer er store, offentligt tilgængelige filer. Kontrollér rettigheder og filstørrelse, før nyt materiale tilføjes.
