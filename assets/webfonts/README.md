# Webfonts

Indeholder skrifttypefiler, herunder Font Awesome-ikoner, som hjemmesidens stylesheets refererer til.

Bevar filnavne og stier, medmindre alle CSS-referencer opdateres tilsvarende. Filerne er statiske ressourcer og skal ikke redigeres som almindelig tekst.

Før en fontfil udskiftes eller fjernes, kontrollér hvilke CSS-regler og ikoner der refererer til den. Font Awesome-filerne indgår i sæt af formater; hvis et sæt opdateres, skal filerne fortsat høre til samme version. Afprøv de berørte ikoner efter ændringen.
