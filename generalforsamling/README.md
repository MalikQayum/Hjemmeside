# Generalforsamling

Denne mappe indeholder `index.html`, den offentlige oversigt over ejerforeningens generalforsamlinger og tilhørende dokumenter.

## Sidens indhold

Siden linker til indkaldelser og referater, årsregnskaber og gældende prisblad. Dokumenterne ligger i `dokumenter/generalforsamling/` og opdeles i undermapperne `referater/` og `regnskab/`. Nogle ældre dokumenter vises i en sammenfoldet arkivsektion på siden.

## Vedligeholdelse

Når et dokument tilføjes, skal filen lægges i den relevante dokumentmappe, og linket på `index.html` skal pege på den nøjagtige filsti. Kontrollér både årstal, filnavn og sidehenvisning. Prisbladet og andre gældende oplysninger skal følge de senest godkendte beslutninger; denne README er ikke en officiel kilde til foreningsregler.
