# Udlejning (`/udlejning/`)

Denne mappe indeholder `index.html`, vejlednings- og dokumentsiden om udlejning af ejerlejligheder, regler og begrænsninger for korttidsudlejning (Airbnb) samt foreningens officielle udlejningsblanket i **Ejerforeningen Skyttegårdvej 1-11 Vigerslevvej 144-148**.

---

## Sidens emner og regelsæt

### 1. Advarsel: Regler for korttidsudlejning (Airbnb) og forbud mod erhverv
Ejerforeningens vedtægter (§ 30) fastsætter strenge grænser for korttidsudlejning for at bevare et trygt og roligt bomiljø:
- **Grænse for Airbnb og ferieudlejning:** Korttidsudlejning må højst finde sted med op til **4 separate udlejninger** og maksimalt **30 dage sammenlagt pr. kalenderår**. Al korttidsudlejning derudover er strengt forbudt.
- **Oplysningspligt over for bestyrelsen:** Ejeren skal forud for enhver korttidsudlejning skriftligt underrette bestyrelsen om lejerens navn, kontaktoplysninger samt den præcise lejeperiode.
- **Forbud mod erhverv og hoteldrift:** Lejligheder og kælderrum må ikke anvendes til erhverv, hotelvirksomhed eller permanent ferieudlejning.
- **Ingen separat fremleje:** Lejede parkeringspladser og kælderrum må ikke udlejes eller overdrages særskilt til andre.
- **Sanktioner ved overtrædelse:** Tilsidesættelse af reglerne eller manglende underretning betragtes som **grov pligtforsømmelse**, der kan medføre pålæggelse af bod eller beslutning om **eksklusion** af ejerforeningen.

### 2. Procedure for udlejning (2-kolonne layout)
- **Trin 1: Udfyld udlejningsblanket:** Hent foreningens officielle blanket (PDF eller Word), og udfyld adresse, ejers oplysninger, lejers navn samt udlejningsperiode.
- **Trin 2: Send til bestyrelsen:** Den udfyldte og underskrevne blanket sendes til bestyrelsen på `bestyrelse@skyttegaardvej.dk`, så udlejningen kan blive registreret og godkendt.
- **Trin 3: Autoriseret navneskilt på postkassen:** Navneskiltet på postkassen udskiftes via foreningen mod gældende gebyr (`price-004`). På dørtelefonen vises ikke navn, men kun adressen. Egne klistermærker er ikke tilladt og afrenses for ejerens regning (`price-005`).
- **Trin 4: Instruér din lejer:** Gennemgå foreningens Husorden og vedtægter samt reglerne for affalds- og storskraldssortering med lejeren før indflytning.

### 3. Betingelser og ejerens fortsatte ansvar
Ved godkendelse af udlejning påtager ejeren sig bl.a. følgende forpligtelser:
- **Overholdelse af vedtægter og husorden:** Lejer forpligter sig til at overholde foreningens gældende vedtægter og husorden.
- **Al kommunikation via ejeren:** Al kommunikation med DEAS og bestyrelsen foregår udelukkende skriftligt via ejeren og ikke direkte med lejeren.
- **Fremleje af enkelte værelser:** Tilladt, når ejeren fortsat selv bebor mindst ét værelse, og det samlede antal beboere (inkl. børn) ikke overstiger antallet af værelser.
- **Ejerens hæftelse (§ 24):** Ejeren hæfter for lejers adfærd; ved retsstridig adfærd eller gentagne husordensovertrædelser kan foreningen efter 3 måneders frist overtage udlejerbeføjelserne og opsige eller ophæve lejemålet.

## Foreningens udlejningsblanket (`#blanket`)

Nederst på siden findes direkte adgang til den officielle blanket i to formater:
- **PDF-format:** `dokumenter/udlejning/udlejningsblanket.pdf` (til direkte gennemsyn eller udskrivning).
- **Word-format (.docx):** `dokumenter/udlejning/udlejningsblanket.docx` (til digital udfyldelse på computer).
- **Indsendelse:** Kan mailes direkte til bestyrelsen på `bestyrelse@skyttegaardvej.dk`.
