# Kælderrum

Indeholder informationssiden om leje af kælderrum, vilkår, betaling og eventuel venteliste samt kontaktmuligheder.

Redigér `index.html`, når den offentlige information ændres. Hvis indholdet skal indgå i chatbotten, skal sidens sti også være med i `chatbot/config/knowledge-config.json`, og vidensdatabasen skal genbygges.
