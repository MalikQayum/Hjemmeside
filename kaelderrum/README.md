# Kælderrum

Denne mappe indeholder `index.html`, informationssiden om leje af kælderrum, vilkår, betaling og eventuel venteliste.

Siden indeholder også en kontaktformular til bestyrelsen. Den bruger de fælles formularfunktioner i `assets/js/contact-form.js` og styling fra `assets/css/contact-form.css`.

Redigér `index.html`, når de offentlige oplysninger eller formularens emne ændres. Kontrollér lejevilkår og eventuelle ventelisteoplysninger mod bestyrelsens aktuelle praksis. Hvis siden skal indekseres af chatbotten, skal dens sti være på allowlisten i `chatbot/config/knowledge-config.json`; genbyg og validér derefter vidensdatabasen.
