# Kontakt

Denne mappe indeholder `index.html`, kontaktsiden med kontaktoplysninger til bestyrelsen og relevante administratorer og leverandører.

Siden har separate kontaktkort og ankerlinks, som andre sider kan henvise direkte til. Hvis et korts ID eller URL ændres, skal interne links på hjemmesiden også kontrolleres.

Redigér `index.html`, når kontaktoplysninger ændres. Kontrollér e-mailadresser, telefonnumre, åbningstider og eksterne links mod de aktuelle oplysninger, før ændringen publiceres. Undgå at kopiere kontaktoplysninger til flere sider, hvis et link til det relevante kontaktkort kan bruges i stedet.
