# Ejerforeningen Skyttegård / Vigerslev

Hjemmeside for Ejerforeningen Skyttegård/Vigerslev (Skyttegårdsvej 1-11 og Vigerslevvej 144-148 i Valby).

## Sider og Funktioner
- **Forside** (`/`)
- **Velkomstbrev** (`/velkomstbrev/`)
- **Husorden og vedtægter** (`/husorden-vedtaegter/`) - Integreret PDF.js fremviser af dokumenter.
- **Nyheder** (`/nyhed/`) - Live visning af Word-nyhedsbrev (`.docx`).
- **Parkering** (`/parkering/`) - Interaktiv parkeringsventeliste samt direkte kontaktformular til bestyrelsen (side-om-side layout).
- **Kontakt** (`/kontakt/`) - Oversigt over bestyrelse, administrator (DEAS), forsyning og håndværkere i kort-layout.
