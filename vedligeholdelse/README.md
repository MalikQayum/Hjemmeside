# Vedligeholdelse

Denne mappe indeholder `index.html`, en praktisk oversigt over vedligeholdelsesansvar og procedurer for ejere og ejerforeningen.

## Sidens indhold

Siden beskriver indvendige forhold i lejligheder, fælles og udvendig vedligeholdelse samt varsling ved planlagt vandlukning. Den henviser til relevante kontaktkort på `/kontakt/` og til siden om nøglekort og nøglebrikker.

## Vedligeholdelse

Siden er vejledende og erstatter ikke de gældende vedtægter, aftaler eller bestyrelsens anvisninger. Kontrollér ansvarsfordeling og kontaktoplysninger mod de aktuelle kilder, før oplysninger ændres. Akutte driftsforhold og planlagt arbejde skal beskrives tydeligt og må ikke forveksles med almindelige vedligeholdelsesråd.
