# Nøglekort og nøglebrikker

Indeholder siden `index.html` med information om foreningens elektroniske adgangssystem samt bestilling, udlevering og spærring af nøglekort og nøglebrikker.

Redigér siden, når de offentlige procedurer ændres. Regler og procedurer skal følge bestyrelsens godkendte beslutninger.
