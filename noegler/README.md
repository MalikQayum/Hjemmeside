# Nøglekort og nøglebrikker

Denne mappe indeholder `index.html` med information om foreningens elektroniske adgangssystem samt bestilling, udlevering og spærring af nøglekort og nøglebrikker.

Siden har en formular til bestilling, mistede eller defekte brikker og spørgsmål. Formularen bruger `assets/js/contact-form.js`; bestillingsfelter og beskedfelter vises efter den valgte henvendelsestype.

Redigér siden, når de offentlige procedurer eller priser ændres. Kontrollér at formularens felter, valgmuligheder og besked stemmer overens med den gældende procedure. Regler og procedurer skal følge bestyrelsens godkendte beslutninger.
