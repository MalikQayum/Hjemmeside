# Referater

Her arkiveres PDF-referater fra ejerforeningens ordinære og ekstraordinære generalforsamlinger. Filnavne følger mødeåret og angiver mødetypen, for eksempel `2026-gf-referat.pdf` og `2026-xgf-referat.pdf`.

Tilføj et referat med et entydigt årstal og mødetype, og opdatér derefter oversigten på `generalforsamling/index.html`. Bevar tidligere referater som historisk arkiv.
