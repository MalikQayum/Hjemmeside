# Regnskaber

Denne mappe indeholder ejerforeningens regnskaber i PDF-format. Filnavne angiver regnskabsåret, for eksempel `2025-regnskab.pdf` eller `2009-2010-regnskab.pdf`.

Når et regnskab tilføjes, skal linket på `generalforsamling/index.html` pege på den præcise fil. Kontrollér at årstallet i linkteksten svarer til dokumentet, og behold ældre regnskaber som arkiv.
