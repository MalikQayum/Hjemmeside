# Udlejningsblanket

Denne mappe indeholder ejerforeningens udlejningsblanket i PDF- og Word-format. Hjemmesidens side `/udlejning/` linker direkte til begge filer.

Når blanketten revideres, kontrollér at PDF- og Word-udgaver har samme indhold og er den version, bestyrelsen har godkendt. Opdatér begge filformater og verificér downloadlinkene på udlejningssiden.
