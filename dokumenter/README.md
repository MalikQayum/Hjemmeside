# Dokumentarkiv

Denne mappe samler dokumenter, der linkes til fra hjemmesidens informationssider. Filerne er statiske webressourcer og kan åbnes eller downloades via deres relative URL'er.

## Mapper

- `forening/`: foreningsdokumenter, herunder vedtægtsfiler.
- `generalforsamling/`: historiske og aktuelle dokumenter fra generalforsamlinger.
- `udlejning/`: PDF- og Word-udgaver af udlejningsblanketten.

## Vedligeholdelse

Når en fil udskiftes eller tilføjes, skal links på hjemmesiden pege på det korrekte filnavn og den korrekte undermappe. Bevar versions- og årstal i filnavne, hvor det er relevant, og kontrollér at en udgave er godkendt og gældende, før den betegnes som officiel. Offentliggør ikke dokumenter med personoplysninger, der ikke skal være offentligt tilgængelige.
