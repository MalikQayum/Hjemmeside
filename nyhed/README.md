# Nyheder og nyhedsbrev

Denne mappe indeholder `index.html`, hjemmesidens nyhedsside. Den viser relevante meddelelser og gengiver indhold fra `Nyhedsbrev.docx` ved hjælp af dokumentviseren i `assets/js/docx-viewer.js`.

Kontrollér både sidens indlejring og det aktuelle nyhedsbrev, når indhold opdateres. OneDrive-workflowet kan hente den seneste nyhedsbrevsfil til repository-roden. Chatbotten kan indeksere den godkendte nyhedsside og nyhedsbrevsfilen via allowlisten i `chatbot/config/knowledge-config.json`.
