# Nyheder og nyhedsbrev

Indeholder hjemmesidens nyhedsside. Siden viser nyhedsbrev og relevante meddelelser, herunder dokumentindhold fra repository'ets `Nyhedsbrev.docx`.

Kontrollér både sidens `index.html` og det aktuelle nyhedsbrev, når indholdet opdateres. Chatbotten kan indeksere den godkendte nyhedsside og nyhedsbrevsfilen via sin kildekonfiguration.
