# Affald og storskrald

Denne mappe indeholder den offentlige side om affaldssortering, storskraldsrum og fællesarealer.

## Sidens indhold

`index.html` beskriver placeringen af skralderum og miljøskab, regler for sortering og henstilling samt rengøring af fællesarealer. Siden bruger `assets/css/home.css`, billedet `images/Storskraldrum.png` og videoerne i `assets/video/`.

## Vedligeholdelse

Kontrollér oplysninger om placering, sortering, afhentning og gebyrer mod de gældende kommunale regler og foreningens beslutninger, før siden ændres. Hold billedets markering og videoernes placeringer opdateret, hvis fællesarealerne ændres. Ved spørgsmål om rengøring eller fællesarealer henviser siden til bestyrelsen via kontaktsiden.
